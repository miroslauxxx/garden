```c
char *ft_strjoin(char const *s1, char const *s2);
```
DESCRIPTION:	
	`Allocates memory (using malloc(3)) and returns a new string, which is the result of concatenating ’s1’ and ’s2’.`

RETURN VALUE:
	The new string. NULL if the allocation fails.
